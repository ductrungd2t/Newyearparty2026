# Thiệp cưới Đức Trung & Thu Hương

Website thiệp cưới tĩnh, phù hợp triển khai miễn phí bằng GitHub Pages.

## Chạy thử
Mở `index.html` bằng trình duyệt hoặc dùng VS Code + Live Server.

## Thay ảnh
Tạo/copy ảnh vào `assets/` rồi sửa `.hero-photo` và các `.gallery-item` trong `index.html`/`style.css` thành ảnh thật. Ví dụ:
```css
.hero-photo { background: url('assets/hero.jpg') center/cover no-repeat; }
```

## Nhạc nền
Đặt file MP3 tên `wedding-song.mp3` vào thư mục `assets/`. Trình duyệt chỉ cho phát nhạc sau khi khách bấm “Mở thiệp”.

## GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload toàn bộ file/thư mục trong project này vào nhánh `main`.
3. Vào Settings → Pages.
4. Build and deployment: Deploy from a branch.
5. Chọn `main` và `/ (root)` → Save.
